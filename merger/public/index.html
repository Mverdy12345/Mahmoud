📚 توثيق API — للمطورين

واجهة برمجية عامة بلا تسجيل دخول مع CORS مفتوح — الأخطاء بصيغة {"error":"..."}

الطريقةالمسارالوظيفة
POST/api/jobsإنشاء مهمة دمج
POST/api/upload?job=&seq=&chunk=رفع أجزاء الملفات (ثنائي ≤4MB)
POST/api/jobs/{id}/processتنفيذ الدمج كاملًا → رابط الناتج
GET/api/jobs/{id}الحالة + التقدم + الرابط عند الاكتمال
GET/api/jobs/{id}/videoبث الناتج مع Range، و ?download=1 للتحميل
DELETE/api/jobs/{id}حذف فوري شامل
GET/api/configالحدود العامة + version
GET/api/cronحذف المهام المنتهية (يومي)
curl -X POST /api/jobs \
  -H "Content-Type: application/json" \
  -d '{"videos":["https://site.com/clip1.mp4","https://site.com/clip2.mp4"]}'
# → {"jobId":"...","status":"queued","statusUrl":"...","processUrl":"...","expiresAt":"..."}

curl -X POST /api/jobs//process
# → {"status":"done","videoUrl":"/api/jobs//video","size":...,"duration":...,"resolution":"WxH"}

curl /api/jobs/            # الحالة والتقدم
curl -OJ /api/jobs//video?download=1   # تنزيل الناتج
curl -X DELETE /api/jobs/  # حذف فوري

الحالات: queued → (uploading) → processing → done | failed — الحدود: 10 مقاطع، 200MB لكل مصدر، 150MB للناتج، 600 ثانية مجموع المدد، والملفات تُحذف بعد 24 ساعة.
